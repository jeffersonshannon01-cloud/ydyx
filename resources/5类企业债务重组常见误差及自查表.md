# 5 类企业债务重组常见误差及自查表

> 一份 15 分钟可以自查完的清单。用于：① 判断你的企业属于哪个象限；② 避免在重组路上踩最常见的 5 个坑。
> 基于"已处理债权资产包超 69 亿元"的实战经验提炼，非法律意见，具体方案请结合律师评估。

---

## 第一部分：先看你的企业在哪个象限

用两个维度快速定位：**经营现金流** × **核心资产**。

| 象限 | 经营现金流 | 核心资产 | 策略 |
|---|---|---|---|
| **I 类（最优）** | 有 | 有 | 资产抵偿 + 长期分期组合 |
| **II 类（次优）** | 有 | 无 | 停息挂账 + 长期分期 |
| **III 类（攻坚）** | 无 | 有 | 资产处置 + 执行和解 |
| **IV 类（转介）** | 无 | 无 | 建议走破产清算程序 |

**自查问题**

1. 过去 3 个月，经营性现金净流入是正还是负？（看银行流水，不看账面利润）
2. 毛利率是否稳定在 15% 以上？（低于 5% 且持续下降 = 危险信号）
3. 前五大客户占比是否低于 50%？（单一客户 >80% = 危险信号）
4. 资产负债率是否低于 70%？（>85% 或资不抵债 = 危险信号）
5. 核心经营性资产（土地、厂房、设备）是否被查封/挂拍？

---

## 第二部分：5 类常见误差 + 自查

### 误差 1：把"短期清零"当目标，而不是"可持续履约"

**错误做法**：一上来就承诺"3 个月还清全部债务"，没有区分紧急风险债务和常规债务。

**正确做法**：先做全域尽调，把债务分为"紧急风险"（将被执行/限高/失信）和"常规"，优先处理紧急项，保留经营周转资金。

**自查**

- [ ] 是否已归集全部合同、账单、传票、判决书？
- [ ] 是否核算了合法本金、合规利息、可减免项？
- [ ] 是否排查了账户/房产/土地/车辆的查封抵押冻结状态？
- [ ] 是否测算了月度净现金流、偿债能力？
- [ ] 是否区分了紧急风险债务与常规债务？

---

### 误差 2：口头承诺债权人，不签书面协议

**错误做法**："银行那边我打过招呼了，不会催了"——所有协商结果都是口头意向。

**正确做法**：所有谈判结果必须落到《债务和解协议》《债务重组协议》《执行和解协议书》《资产抵债协议》等书面文件，并同步法院备案（涉执行案件）。

**自查**

- [ ] 大额核心债权是否已一对一专项约谈？
- [ ] 小额分散债权是否已统一协商、统一标准？
- [ ] 是否争取到停止催收、停止新增起诉、暂缓资产处置、停息减罚？
- [ ] 是否所有协商结果都签了书面意向？
- [ ] 涉执行案件是否递交法院（中止执行、解封、解冻、撤回拍卖）？
- [ ] 是否约定了违约兜底条款（正常履约永久减免罚息，二次违约恢复原判决执行力）？

---

### 误差 3：方案一刀切，没有分层定制

**错误做法**：对所有债务都用"分期"，不管债务人是"有现金流无资产"还是"有资产无现金流"。

**正确做法**：按债务人类型选 5 类方案之一：

| 方案 | 适用场景 | 模式 |
|---|---|---|
| A | 有现金流、无大额资产 | 停息挂账 + 罚息减免 + 长期分期 |
| B | 有资产、现金流不足 | 资产作价抵偿 + 部分现金分期 |
| C | 已起诉/判决/强制执行 | 执行和解协议 + 法院备案 |
| D | 具备持续经营价值 | 债务重组、债转股、债权延期 |
| E | 商贸/服务/产品企业 | 合法易货对冲债务 |

**自查**

- [ ] 是否已识别企业属于 A/B/C/D/E 哪种类型？
- [ ] 方案是否与现金流/资产状态匹配？
- [ ] 是否预留了 3-6 个月的经营周转资金？（避免"还债致死"）
- [ ] 是否建立了《月度偿债履约台账》（固定还款日/金额）？

---

### 误差 4：忽视信用修复，结案才想起征信

**错误做法**：债务清零了，但老板/法人还在失信被执行人名单、限高名单，或者征信逾期记录没更新。

**正确做法**：结案后同步做四件事——

1. 索取《债务结清证明》《债权终结确认书》
2. 申请案件结案、撤销执行、移除失信与限高
3. 申请征信逾期更新、不良记录终止
4. 复盘债务爆发根源，优化财务/融资/担保制度

**自查**

- [ ] 是否已申请撤销执行？
- [ ] 是否已移除失信/限高？
- [ ] 征信报告是否已更新（逾期记录终止）？
- [ ] 是否做了债务爆发根源复盘？
- [ ] 财务/融资/担保制度是否优化？

---

### 误差 5：把"资产抵债"当成唯一出路

**错误做法**：一遇到大额债务就卖房卖地，没有评估资产是"核心经营性资产"还是"闲置资产"。

**正确做法**：先做三维健康诊断（经营/债务/资产），再判断资产处置节奏。核心经营性资产优先保，闲置资产可先处置抵偿。

**自查**

- [ ] 是否对核心经营性资产做了产权清晰度检查？
- [ ] 抵押率是否低于 50%？（>80% 或超额抵押 = 危险）
- [ ] 是否区分了核心资产和闲置资产？
- [ ] 资产处置节奏是否与偿债计划匹配？

---

## 第三部分：15 分钟自查流程

1. 打印/保存本表，填写象限判断（5 分钟）
2. 逐项打勾 5 类误差自查（8 分钟）
3. 标记"是"的比例：<30% 说明基础较好，可走 A/D 方案；>70% 说明风险高，建议先做全域尽调（2 分钟）
